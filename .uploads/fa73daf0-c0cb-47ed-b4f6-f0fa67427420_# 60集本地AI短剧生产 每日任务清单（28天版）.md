# 60集本地AI短剧生产 每日任务清单（28天版）
**适配配置**：RTX 5080 16GB + 锐龙9 9950X3D + 48GB 内存
**适用方向**：漫剧 / 轻写实风格竖屏短剧，纯本地产出为主
**核心原则**：先做3集样片验证效果，再启动全量量产；AI任务错峰运行，不影响日常游戏使用

---

## 第一阶段：筹备与环境跑通（第1-4天）
**阶段目标**：完成全部工具环境搭建，敲定剧本与核心人设，跑通基础生图流程

### 第1天：环境搭建与基础功能验证
**当日核心任务**
1. 下载ComfyUI一键整合包（推荐秋叶/星空整合包），解压至非中文路径磁盘
2. 通过ComfyUI-Manager安装必备插件：IP-Adapter、ControlNet Auxiliary、AnimateDiff、VideoHelperSuite、MuseTalk/Wav2Lip插件
3. 下载1套SD 1.5底模（写实选Realistic Vision v6，漫剧选Anything V5）+ 对应VAE，放入对应模型文件夹
4. 搭建最简生图工作流，成功生成1张512×768分辨率的竖屏测试图
5. 配置启动参数，添加 `--medvram --cuda-malloc --force-fp8` 显存优化项

**当日交付物**
- 可正常启动、无报错的ComfyUI运行环境
- 1张成功生成的测试图，验证底模、插件加载正常

**注意事项**
- 新手优先使用一键整合包，切勿从零配置Python/CUDA环境
- 暂不触碰SDXL、大型视频模型，先跑通基础流程

### 第2天：剧本定稿与分镜模板搭建
**当日核心任务**
1. 敲定短剧题材（优先选择场景≤8个、核心角色≤5个的都市/甜宠/逆袭类）
2. 完成60集完整剧本：单集400-600字，每集结尾留钩子，每3集设置1个小反转
3. 制作标准化分镜表模板，将第1集拆分为15-20个镜头，单镜头时长控制在3-4秒
4. 统计全剧核心场景清单，标注每个场景的出场角色与大致戏份

**当日交付物**
- 60集完整剧本文档
- 可复用的分镜表模板 + 第1集分镜样例
- 全剧场景与角色统计清单

### 第3天：角色人设与训练素材准备
**当日核心任务**
1. 完成3-5个核心角色的人设设定：外貌、服装、性格、标志性特征
2. 使用ComfyUI生成每个角色的20张素材图，覆盖正面、侧面、45°角、不同表情、轻微动作，保持服装发型完全统一
3. 为每张素材图编写对应txt标注文件，统一加入专属触发词（例：`zhunan, 黑色西装, 白色衬衫`）
4. 按角色分类归档素材图与标注文件

**当日交付物**
- 核心角色人设文档
- 每个角色20张高清素材图 + 对应标注文本

**注意事项**
- 素材图背景尽量干净简洁，减少杂物干扰LoRA训练效果
- 触发词设置为独一无二的组合，避免与底模原有概念冲突

### 第4天：全工具链验证与工作流模板化
**当日核心任务**
1. 下载ControlNet模型（OpenPose、Canny、Depth）、AnimateDiff运动模型，放入对应文件夹
2. 下载kohya_ss LoRA训练一键包，完成安装并验证可正常启动
3. 搭建可复用的「生图+LoRA+ControlNet」标准工作流，保存为模板文件
4. 测试IP-Adapter FaceID锁脸功能，验证角色一致性效果
5. 完成全工具链联调，确保无报错、无缺失依赖

**当日交付物**
- 所有必备模型、插件安装完成且可正常调用
- 可直接复用的生图工作流模板

**阶段检查点**：所有工具运行稳定，可按需求生成指定人物、指定构图的图片

## 第二阶段：核心资产与样片验证（第5-9天）
**阶段目标**：产出专属角色LoRA，完成3集完整样片，跑通全流程后再启动全量制作

### 第5天：核心角色LoRA训练
**当日核心任务**
1. 打开kohya_ss训练工具，导入第一个角色的训练素材与标注
2. 按16GB显存最优参数设置训练配置：
   - 基础模型：对应选用的SD 1.5底模
   - 训练分辨率：512×768（竖屏适配）
   - Network Rank (Dim)：32，Network Alpha：16
   - 优化器：AdamW8bit，Batch Size：2
   - 学习率：Unet 5e-5，文本编码器 1e-5
   - 开启梯度检查点、潜像缓存
3. 依次完成3个核心角色的LoRA训练
4. 抽取每个模型中间epoch版本测试，选出泛化性与还原度最佳的一版

**当日交付物**
- 3个核心角色的最终LoRA模型文件

**注意事项**
- 避免训练过拟合，人物可识别、服装发型统一即可，无需追求百分百一致
- 训练过程尽量不操作其他大型软件，保证训练稳定

### 第6天：前3集关键帧批量生成
**当日核心任务**
1. 对照分镜表，整理前3集所有镜头的提示词、景别、场景信息
2. 套用生图工作流模板，按场景集中生成关键帧，同一场景固定光影参数与相近随机种子
3. 逐张筛选素材：人脸崩坏、构图不符、服装不统一的直接重抽
4. 按「集数-镜头号」规则命名，分文件夹归档

**当日交付物**
- 前3集约50个镜头的合格静态关键帧

**注意事项**
- 不合格素材当日完成重抽，不要留到视频阶段再补救
- 同一场景使用相近种子，保证光影、色调一致性

### 第7天：前3集动态视频生成
**当日核心任务**
1. 搭建AnimateDiff工作流：关键帧 → 运动模型 → ControlNet姿态控制 → 视频输出
2. 设置基础生成参数：24fps，单镜头3-4秒，运动强度0.3-0.5
3. 批量生成前3集所有镜头的动态视频
4. 筛选合格素材，肢体崩坏、画面闪烁严重的调整参数后重制

**当日交付物**
- 前3集所有镜头的动态视频素材

**注意事项**
- 对话类静态镜头优先制作，动作幅度大的镜头适当降低运动强度
- 单镜头时长不超过4秒，避免显存溢出与画面崩坏

### 第8天：配音制作与口型对齐
**当日核心任务**
1. 本地部署ChatTTS一键包，导入前3集台词，批量生成多角色配音音频
2. 按镜头拆分音频文件，命名规则与视频素材一一对应
3. 使用Wav2Lip一键工具，为每个镜头做基础口型对齐
4. 收集适配题材的商用免费BGM、转场音效，搭建基础音效库

**当日交付物**
- 前3集分镜头配音音频
- 完成口型对齐的视频片段
- 基础BGM、音效素材库

### 第9天：样片剪辑与效果验收
**当日核心任务**
1. 打开剪映专业版，按集数拼接镜头素材与对应音频
2. 一键生成字幕，调整字体大小、位置与样式
3. 添加转场、BGM、音效，做基础统一调色
4. 导出3集完整样片，完成全流程质检
5. 可提交红果平台测试评级，验证内容是否符合上线标准

**当日交付物**
- 3集完整成片样片

**阶段检查点**：角色一致性达标、画面流畅、节奏符合短剧要求，达到平台A级及以上标准后，启动全量制作

## 第三阶段：全量批量生产（第10-21天，共12天）
**阶段目标**：按场景集中生产，最大化提升效率；夜间挂机运行任务，不占用日常使用时间

### 第10天：全剧镜头分类与生产排期
**当日核心任务**
1. 将剩余57集所有镜头，按场景归类统计，汇总每个场景的镜头总数、出场角色
2. 制定12天生产排期：4天关键帧生成 + 6天动态视频生成 + 2天补漏修复
3. 整理所有场景的提示词模板、光影参数预设
4. 统一命名规则与文件夹归档结构

**当日交付物**
- 全剧场景镜头统计表
- 12天批量生产每日任务排期表

### 第11-14天：全剧静态关键帧批量生成（共4天）
**每日固定任务**
1. 当日处理2个主场景的全部镜头，复用固定提示词与光影参数
2. 白天负责调参、筛选合格图，不合格素材当场重抽
3. 夜间挂机批量生成剩余常规镜头，最大化硬件利用率
4. 当日素材按「场景-集数-镜头号」命名归档

**每日交付物**
- 当日对应场景的全部合格关键帧图片

**注意事项**
- 永远按场景集中生产，不要按集数逐集制作，减少参数调整损耗
- 夜间任务设置完成自动关机，省电且不影响次日使用

### 第15-20天：全剧动态视频批量生成（共6天）
**每日固定任务**
1. 导入前一天生成的关键帧，批量转换为动态视频
2. 搭配ControlNet OpenPose控制人物骨骼动作，减少肢体崩坏
3. 白天筛选素材、调整参数重制不合格镜头
4. 夜间挂机批量生成常规对话类镜头

**每日交付物**
- 约80-100个合格动态镜头素材

**注意事项**
- 动作复杂的镜头单独调低运动强度，增加重抽次数选优
- 随时监控显存占用，避免爆显存中断任务

### 第21天：全素材盘点与补漏修复
**当日核心任务**
1. 对照分镜表逐一核对60集所有镜头，统计缺失、不合格的素材
2. 统一重制所有不合格、遗漏的镜头
3. 按集数整理全部动态视频素材，完成分类归档
4. 复盘生产效率，调整后续后期阶段排期

**当日交付物**
- 60集全部镜头的动态素材，无遗漏、无明显崩坏

**阶段检查点**：全片素材齐全，可直接进入后期剪辑阶段

## 第四阶段：后期制作与上线准备（第22-28天）
**阶段目标**：批量完成全片后期，统一品质标准，最终提交平台审核

### 第22-23天：全剧配音与口型对齐（共2天）
**每日核心任务**
1. 批量导出全剧台词，使用ChatTTS生成所有角色配音
2. 按镜头拆分音频文件，与视频素材一一对应
3. 批量完成口型对齐，近景、特写镜头重点优化
4. 完成全片音效、BGM的筛选与分类

**交付物**
- 全剧分镜头配音音频
- 完成口型对齐的全部最终视频片段

### 第24-26天：分批次剪辑成片（共3天）
**每日核心任务**
1. 每日完成20集的剪辑工作
2. 先制作1集标准剪辑模板：固定字幕样式、转场风格、调色参数
3. 后续集数套用模板，仅替换素材与调整音效卡点
4. 每完成10集统一检查一遍节奏、字幕错误

**每日交付物**
- 20集成片初稿

**注意事项**
- 善用剪映批量功能，避免逐帧手动调整
- 字幕位置避开竖屏安全区，保证静音观看体验

### 第27天：全片统一质检与优化
**当日核心任务**
1. 统一全片音量比例：人声清晰为主，BGM不盖过人声
2. 统一全片色调、字幕样式，修正穿帮画面、台词错误
3. 抽查重点集数的画面稳定性、角色一致性，修复崩坏片段
4. 制作统一的片头、片尾、集数标题
5. 完成全片最终版本导出

**当日交付物**
- 60集最终成片终稿

### 第28天：平台投稿与上线准备
**当日核心任务**
1. 制作6张以上不同风格的剧集封面图，适配平台推荐位
2. 撰写剧集简介、每集标题，优化钩子关键词
3. 按红果平台要求整理文件格式、命名规范
4. 提交平台审核，记录审核进度，准备驳回修改预案

**当日交付物**
- 完整投稿素材包
- 平台提交审核完成

## 配套守则
### 效率优化守则
1. **模板复用**：生图工作流、剪辑模板、提示词模板提前固化，每次仅修改核心变量
2. **错峰运行**：人工调参、筛选、剪辑放在白天；批量生成任务放在夜间/闲置时间
3. **集中生产**：按场景维度批量制作，减少模型切换、参数调整的时间损耗

### 硬件使用提示
1. 打游戏前彻底关闭ComfyUI、训练工具等AI软件，释放全部显存，游戏体验无任何影响
2. AI生成属于显卡正常计算负载，温度与3A游戏持平，正常散热即可，不会损伤硬件
3. 所有AI模型、素材可存放在单独磁盘分区，与游戏、系统文件完全隔离，不影响系统流畅度
